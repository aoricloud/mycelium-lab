Le cube de nourriture

Le vrai moteur de Mycelium, en volume : une goutte de nourriture diffuse dans un cube de 32 cases de côté, calculée ici par le même code que les tests, au bit près. Faites tourner le cube à la souris ou au doigt. Le mycélium y pousse sur une page à côté : la colonie dans le cube.
